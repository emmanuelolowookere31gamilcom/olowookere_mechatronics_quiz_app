# Mechatronics Quiz App

## What it does

The Mechatronics Quiz App is a Python application that tests basic knowledge of mechatronics engineering. It presents multiple-choice questions, checks answers and calculates the user's final score and grade.

## How to run it

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python mechatronics_quiz.py

## Sample output

MECHATRONICS QUIZ

Total questions: 8
Correct answers: 6
Wrong answers: 2
Percentage: 75.0%
Grade: Very Good

## My own twist

I introduced Smart Revision Mode. This feature allows users to review questions they answered incorrectly, read explanations and attempt those questions again. It also calculates their revision score.

## What I learned

I learned how to use Python functions, lists, loops, conditional statements and input validation. I also learned how to calculate percentages and organise a working quiz application.
